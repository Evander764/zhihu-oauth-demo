## 运行方式

适配现有 Vercel 函数：用户授权返回后，在同一次后端请求中读取创作、关注、收藏夹、收藏夹内容和近期收藏，每类最多一条。OAuth Token 只在该请求内存中使用，不跨函数实例保存；再次读取须重新授权。没有把 Skill 的本机内存会话当作 Vercel 的持久会话。

`/auth/callback` 转到既有 `/api/oauth-callback`。旧路径继续可用。`/api/health` 提供版本与提交标识，`/api/oauth/status` 和 `/api/status` 只返回公开配置与就绪状态。

## 回调登记门槛

只有 App 661 的真实回调登记得到确认后，才把 `ZHIHU_OAUTH_CALLBACK_REGISTERED` 设置为 `true` 并重新部署。缺省值为未登记，前后端都禁止发起授权。凭证存在不代表凭证有效、回调已登记或真实 OAuth 已成功。
